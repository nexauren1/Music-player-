# Music Player

Music Player is a polished offline-first Android music player built with Kotlin, Jetpack Compose and AndroidX Media3.

Music Player 1.5.8 is the production release candidate for public distribution.

- English and Portuguese interface
- Redesigned compact mini player
- Persistent equalizer engine
- Free 5-band equalizer + Premium 10-band mixer
- Premium Bass Boost, 3D Space, Loudness and Reverb
- Premium DJ presets and expanded themes/backgrounds
- Local-first playback with background Media3 service
- In-app update checker with signed APK verification
